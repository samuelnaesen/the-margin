# Mood board v1 — The Margin

Tone: eerie but warm. A 1960s typesetting manual where a human editor and "a machine" argue in the margins.

The board image is not stored in this repo, because items 11–14 and 16 come from Are.na with unknown licences. They are **for reference only and must not ship.** Items marked CC0, PDM, BY or BY-SA may be used **with attribution** (BY-SA also requires sharing changes under the same licence).

## What to take from each

| # | Move worth taking |
|---|---|
| 1 | Handwriting squeezed between printed lines and in the outer margin of a real spread. This is our core look. |
| 2, 3, 15 | Little figures living at the foot and edge of the text block. Our clue doodles go here. |
| 3 | Faint ruled construction lines left visible under the text. This could be our "G" key overlay, done in pencil. |
| 4 | A heavy two-column block with a figure set into it. Use it as one "manual" spread. |
| 5 | Widely letterspaced caps on a title page. Use it for the book's cover. |
| 6 | Pencil shelf marks and catalogue stickers. These are tiny clue carriers. |
| 7 | Wood and metal type textures for the typesetting-manual theme. |
| 8, 9, 10 | The machine's voice: manila punch cards, teletype caps, ribbon ink. The machine's notes should look *typed*, not handwritten. |
| 11 | "[No results were found]" set as content. This is exactly the machine's deadpan voice. |
| 12 | Big serif with italics and a narrow side column. This is the BONT-style type feel. |
| 13 | Specimen pages: large type with small numbers and labels. |
| 14 | Registration colour bars and binder holes. These are print-production details for the "manual." |
| 16 | A very tall text column beside one object photo. This is the landing-page layout idea. |

## Direction (draft)
- **Paper:** warm aged cream. **Human ink:** brown-black pencil and fountain pen. **Machine ink:** faded teletype violet/blue. **Accent:** rubric red, used sparingly.
- **Two voices:** human = handwriting font; machine = typewriter/teletype monospace in caps.
- **Type:** a classic book serif with a strong italic for the body and titles.
